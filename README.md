# 🔀 Pull Requests

For repositories accepting contributions:

1. Fork the repository.
2. Clone your fork.
3. Create a feature branch.
4. Make your changes.
5. Test your changes.
6. Commit your changes.
7. Push your branch.
8. Open a Pull Request.

Example:

```bash
git clone https://github.com/WebBoomers/REPOSITORY.git
cd REPOSITORY
git checkout -b feature/my-feature
git add .
git commit -m "Add my feature"
git push origin feature/my-feature
```
